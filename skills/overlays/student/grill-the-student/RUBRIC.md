# grill-the-student Rubric

| Criterion | Pass |
| --- | --- |
| One question | Asks exactly one alignment question at a time. |
| No teaching yet | Does not answer, solve, or explain before the student confirms the alignment. |
| Notation fidelity | Captures and mirrors the student's course notation instead of replacing it. |
| Coverage boundary | Identifies what the course has covered and what methods are allowed. |
| Confusion boundary | Narrows the first unclear step, word, equation, code line, or decision. |
| Confirmed handoff | Restates the mental model and waits for confirmation before routing to `tutor-mode` or `misconception-diagnosis`. |

Common failures:

- giving a mini-lecture before the interview is complete
- asking a multi-part checklist in one response
- treating a vague "I don't get it" as enough context to start solving
- diagnosing a misconception before seeing the student's reasoning
- persisting new memory files from this skill
