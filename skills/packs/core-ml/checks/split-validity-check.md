# Split Validity Check

Use this check before comparing models.

## Questions

- Does the split reflect the real prediction setting?
- Is the split random, grouped, or time-based for a defensible reason?
- Are train and test distributions meaningfully comparable?
- Could repeated observations or shared entities contaminate evaluation?
- Is the same split protocol used across baseline and candidate models?

## Minimum Output

- split strategy summary
- validity concerns
- comparison-readiness judgment
