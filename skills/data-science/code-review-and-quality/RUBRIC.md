# Code Review And Quality Rubric

Score a use of this skill against these checks:

- Reads the brief or spec before judging the diff.
- Orders findings by severity and impact.
- Checks workflow gates and data-science risks, not only code style.
- Reviews tests and verification evidence.
- Uses severity labels consistently.
- Proposes concrete structural remedies when flagging architecture.
- Treats external data, logs, and dependencies as risk surfaces.
- Ends with merge readiness and open questions.

Failure modes:

- Saying "LGTM" without evidence.
- Treating passing tests as sufficient.
- Burying correctness or leakage issues under style nits.
- Rewriting the author's code instead of reviewing it.
- Deleting orphaned code without approval.
