# Plan As Guidance Rubric

Score a use of this skill against these checks:

- Confirms a planning anchor before writing steps.
- Treats the plan as an outcome contract, not a rigid sequence.
- Gives each step intent, acceptance criteria, verification, dependencies, and permitted revision.
- Names allowed revisions and stop conditions.
- Keeps exploratory analysis flexible without allowing unbounded wandering.
- Logs mid-flight changes with evidence and reason.
- Routes missing problem frames, data-audit blockers, and ML feature specs to their owning skills.
- Hands execution-ready work to `incremental-implementation`.

Failure modes:

- Producing a rigid task list with no revision triggers.
- Treating every deviation as failure.
- Allowing "exploratory" to mean no acceptance criteria.
- Starting implementation while planning.
- Duplicating `ml-feature-spec` or `incremental-implementation`.
