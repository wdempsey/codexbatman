# Rubric: Weekly Review

## Passing Standard

The output passes if it:

- states the review window and source coverage
- reads the project config and Research Design and Progress artifact before synthesis
- synthesizes project docs and meeting transcripts into a coherent project view
- produces a three-page overview with strategic reminder, near-term imperatives, and per-person priorities
- appends or prepares a weekly history entry for the configured history tab or section
- distinguishes verified facts from uncertainty
- ties weekly activity to strategic objectives
- identifies owners, actions, blockers, and escalation needs
- preserves data-science workflow gates and human-review needs

## Failure Modes

Fail if the output:

- reads like a raw chronology dump
- omits source gaps
- invents quantitative claims
- ignores the prior dashboard baseline
- skips the Research Design and Progress artifact when it exists
- omits strategic reminder, near-term imperatives, per-person priorities, or weekly history update
- treats live Gmail, calendar, scheduled filing, or outbound actions as part of this skill instead of PR-13 integration work
- presents manager synthesis as approval to advance EDA, modeling, or final reporting
- buries urgent blockers or action items
