# Rubric: Meeting Pre-Brief

## Passing Standard

The output passes if it:

- reads current project artifacts before drafting meeting prep
- states the meeting purpose, attendees, and project context when available
- surfaces decisions, blockers, risks, and owner-specific prompts
- names what should be captured after the meeting
- keeps live calendar/email pulls and scheduled automation out of the skill
- screens for sensitive meetings before using project memory

## Failure Modes

Fail if the output:

- relies on chat memory when project artifacts exist
- produces a generic agenda without project-specific decisions or blockers
- pulls or promises live calendar/email automation
- includes personnel-sensitive material in shared project memory
- omits a post-meeting capture plan
