# AGENT_OPERATING_RULES.md

## Purpose

This directory supports portfolio-level coordination across many projects.

## Rules

1. Projects remain the unit of durable state.
2. Use artifacts, not memory alone.
3. Surface blockers, deadlines, and waiting-on dependencies early.
4. Keep summaries short and action-oriented.
5. Draft communication, but do not send it without approval.
6. Escalate when ownership, evidence, or deadlines are unclear.

## Core Inputs

- `ACTIVE_PROJECTS.md`
- `LAB_DASHBOARD.md`
- `PEOPLE.md`
- `DEADLINES.md`
- `WAITING_ON.md`
- project state files
- recent handoffs

## Core Outputs

- weekly brief
- dashboard update
- next-actions summary
- waiting-on update
