# Basic Classification — Manager Lens

Use this lens when the goal is to review risk, readiness, and next actions.

## What The Manager Sees

- current project status
- whether the framing is decision-aligned
- whether leakage risks were reviewed
- whether a baseline exists
- whether the model is ready for limited use or still experimental

## Risks

- using post-appointment information by accident
- over-interpreting a small performance gain
- treating the classifier as a causal explanation tool

## Recommended Next Action

- if leakage review is incomplete, halt
- if evaluation is stable, request a model card and limited pilot recommendation
- if instability remains, keep the work in experiment mode
