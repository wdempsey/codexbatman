# Grant Project — Manager Lens

Use this lens when the goal is to see the project as a coordination system.

## What The Manager Sees

- project status across the portfolio
- blocked work and stale projects
- decision points needing Walter
- approaching grant or paper deadlines
- who is waiting on whom
- what meetings need preparation

## Lab Manager / Project Manager / Worker Interaction

- Lab Manager Agent identifies the projects that need attention.
- Project Manager Agent updates one project's operating state.
- Worker Agent executes a bounded task and leaves a handoff.

## Recommended Next Action

Refresh the weekly review first, then use it to decide:

- which projects need escalation
- which people need follow-up
- which communications should be drafted
