# Grant Project

This is a synthetic example showing how the Research OS layer coordinates a grant across meetings, deadlines, writing tasks, and handoffs.

## Scenario

A research group is managing a multi-person grant project with student researchers, weekly meetings, funding deadlines, and writing deliverables.

The analytical work still happens inside projects, but the operating challenge is cross-project coordination.

## What This Example Demonstrates

- lab manager view
- project manager view
- worker-agent task routing
- weekly review
- waiting-on list
- next actions
- communication draft policy
