# Grant Project — Execution Lens

Use this lens when the goal is to operate the project and portfolio cleanly.

## Concise Workflow

1. Update project `PROJECT_STATE.md` after each meaningful work session.
2. Record open actions in `NEXT_ACTIONS.md`.
3. Leave a `HANDOFF.md` after scoped worker tasks.
4. Update `ACTIVE_PROJECTS.md`, `WAITING_ON.md`, and `DEADLINES.md` during weekly review.
5. Produce `WEEKLY_REVIEW.md` and refresh `LAB_DASHBOARD.md`.

## Reproducibility And Coordination Checklist

- project state is current
- next actions are assigned
- handoffs exist for recent work
- deadlines are visible
- waiting-on dependencies are visible
- weekly review outputs are current
- draft communications are separated from sent communications

## Final Deliverables

- weekly review
- dashboard update
- updated waiting-on list
- draft agenda or follow-up messages
