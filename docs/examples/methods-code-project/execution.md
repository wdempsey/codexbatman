# Methods / Code Project — Execution Lens

Use this lens when the goal is to execute technical work reproducibly.

## Concise Workflow

1. Update `PROJECT_STATE.md` with the current technical objective.
2. Use repository-memory tools only for structural questions.
3. Record material code or experiment decisions in `decision_log.md`.
4. Leave `workflow_trace.md` entries after meaningful exploration or implementation.
5. Leave a `HANDOFF.md` after a bounded worker session.

## Reproducibility Checklist

- technical objective is explicit
- repository exploration is documented
- decisions are logged
- changed files are traceable
- handoff exists for the next session

## Final Deliverables

- updated project state
- updated decision log
- workflow trace
- handoff note
