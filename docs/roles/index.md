# Choose Your Role

**Start here when you know what kind of help you need, but not which part of the site to open first.**

Codex Batman uses one shared workflow backbone. The role pages change the delivery style and first actions, not the underlying data science standards.

If you are overwhelmed, do not read the whole site. Pick one role page and follow that sequence only.

## Shared Backbone

All three roles run the same sequence: bootstrap, problem framing, data audit, exploratory analysis, modeling, evaluation, and experiment logging. What changes is how Codex helps you move through it — coaching and scaffolding for students, direct execution for practitioners, summarizing and tracking for managers.
