# Student Run — Basic Classification (Cardiac Risk)

This folder contains the artifacts produced during a simulated student session through the
Basic Classification — Learning Lens example. Each file is the output of one workflow gate,
generated via Codex with tutor mode and Socratic prompting.

## Session Context

- **Student**: Alex (first time through; background in biology, some Python)
- **Dataset**: Cleveland Heart Disease — 303 patients, 13 clinical features
- **Objective**: predict cardiac disease presence (binary), ROC-AUC metric
- **Mode**: tutor mode + Socratic scaffolding
- **Gates completed**: all 7

## How To Use This

These files show what a complete student run looks like. When you run the example yourself,
your versions will look different — that's expected. The point is the *shape* of the artifacts:
brief, precise, decision-oriented. Not polished prose.

See [Basic Classification — Learning Lens](../../docs/examples/basic-classification/learning.md)
for the guided walkthrough.
