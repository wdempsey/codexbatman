# Student Run — Linear Regression (California Housing)

This folder contains the artifacts produced during a simulated student session through the
Linear Regression — Learning Lens example. Each file is the output of one workflow gate,
generated via Codex with tutor mode and Socratic prompting.

## Session Context

- **Student**: Alex (returning student; completed basic-classification first)
- **Dataset**: California Housing — 20,640 census tracts, 8 features
- **Objective**: predict median house value (MedHouseVal), RMSE metric
- **Mode**: tutor mode + Socratic scaffolding
- **Gates completed**: all 7

## How To Use This

These files show what a complete student run looks like for a regression problem. Compare
with `examples/basic-classification/student-run/` to see how the same 7-gate backbone
produces different artifacts when the problem type changes (continuous vs. binary target).

See [Linear Regression — Learning Lens](../../docs/examples/analytics-repo/learning.md)
for the guided walkthrough.
