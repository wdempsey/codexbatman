## Misconception Corrected

**Before**: "Ridge regression should dramatically outperform OLS because of multicollinearity."
**After**: Multicollinearity inflates coefficient variance and distorts interpretation — but OLS
predictions can still be accurate if the correlated features together carry real signal.
Ridge fixes the interpretation problem, not primarily the prediction problem. A large RMSE
improvement from ridge would actually suggest a different kind of model misspecification.
